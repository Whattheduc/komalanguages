# Koma语言学习站

专业留学英语备考指导网站

## 项目说明

这是一个现代化的个人教学展示网站，用于展示Koma老师的专业背景和教学特色，包含雅思作文评分演示平台。

## 文件结构

```
article/
├── index.html              # 网站主页（Koma老师个人介绍）
├── styles.css              # 主页样式文件
├── script.js               # 主页交互脚本
│
├── home.html               # 作文批改平台首页
├── home-styles.css         # 首页样式
├── home-script.js          # 首页交互脚本
│
├── grading.html            # 雅思作文评分页面
├── grading-styles.css      # 评分页面样式
├── grading-script.js       # 评分页面交互脚本
│
├── history.html            # 历史评分记录页面
├── history-styles.css      # 历史页面样式
├── history-script.js       # 历史页面交互脚本
│
└── README.md               # 项目说明（本文件）
```

## 功能特点

### 主页 (index.html)
- ✨ 现代化渐变设计
- 📱 完全响应式布局
- 🎨 精美的卡片式信息展示
- 💫 流畅的动画效果
- 🌈 优雅的视觉层次

### 作文批改平台
- 📝 **评分页面** - 输入题目和答案进行模拟评分
- 📊 **四维评分** - 任务回应、连贯衔接、语法使用、词汇使用
- 📈 **历史记录** - 查看历史评分记录，支持筛选和搜索
- 🎯 **实时反馈** - 即时显示评分结果

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件即可查看主页
2. 点击"开始学习"或"雅思写作批改"进入作文批改平台
3. 网站完全基于HTML、CSS和JavaScript，无需任何服务器配置
4. 支持所有现代浏览器（Chrome、Firefox、Safari、Edge等）

## 页面流程

```
index.html (主页)
    ↓
home.html (平台首页)
    ↓
grading.html (评分页面) ←→ history.html (历史记录)
```
